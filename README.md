# Свалка

Интерактивная куча ярлыков: сайты, игры, фильмы и видео. Копайся руками, ищи, выкидывай свои находки.

Сайт статический (GitHub Pages), данные хранятся в Supabase.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт |
| `config.js` | Адрес и публичный ключ Supabase. Пустой — сайт работает в демо-режиме |
| `supabase.sql` | Схема базы, права доступа, защита от спама, стартовые ярлыки |
| `vendor/matter.min.js` | Физический движок (matter-js 0.19, MIT), лежит здесь, чтобы не зависеть от CDN |

## Подключить базу

1. Создай проект на [supabase.com](https://supabase.com) (бесплатный тариф).
2. **SQL Editor → New query** → вставь весь `supabase.sql` → **Run**.
3. **Project Settings → API Keys**: скопируй **Project URL** и **publishable key** (или `anon public`).
4. Впиши их в `config.js`.

⚠️ В `config.js` идёт только publishable/anon ключ. Он публичный по задумке: всё, что можно с ним сделать, ограничено правилами в `supabase.sql`. **Secret / service_role ключ никогда не клади в репозиторий.**

## Модерация

Supabase → **Table Editor → labels** → фильтр `status = pending`.

- Одобрить: поменяй `status` на `approved`. Ярлык появится у всех в течение двух минут.
- Отклонить: `rejected`.
- Сделать ярлык крупнее (после договорённости): поменяй `size` на `M`, `L` или `XL`.

Заявки (крупный ярлык, подъём наверх, вывески, спонсоры, жалобы) — таблица **requests**. Контакты видишь только ты.

## Что защищено

- Посетитель видит только одобренные ярлыки и не может ничего изменить или удалить.
- Нельзя подать ярлык сразу одобренным, крупным или с накрученными открытиями: база сама сбрасывает эти поля.
- Принимаются только ссылки `https://`. Казино, торренты и 18+ по ключевым словам уходят в отклонённые автоматически.
- Лимиты: 5 ярлыков и 10 заявок в сутки с одного IP, не больше 300 ярлыков в очереди на проверку.
- Открытие ярлыка с одного IP засчитывается не чаще раза в час.
- Тексты на странице экранируются (защита от XSS).

## Важно знать

- Бесплатный проект Supabase засыпает примерно после недели без запросов. Разбудить: зайти в панель Supabase.
- Лимит по IP — базовая защита. Если пойдёт массовый спам, следующий шаг — капча Cloudflare Turnstile.
